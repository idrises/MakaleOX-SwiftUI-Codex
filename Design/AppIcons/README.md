# MedLib App Icon Concepts

This folder contains four icon directions for `MedLib / Medical Library`.

- `medlib-icon-concept-a-clinical-book.svg`
  Calm clinical direction. Open-book silhouette with a coral medical cross.

- `medlib-icon-concept-b-premium-monogram.svg`
  Premium direction. Monogram-like medical mark on a darker academic background.

- `medlib-icon-concept-c-pulse-library.svg`
  Library-forward direction. Bookshelf bars with a pulse line across the center.

- `medlib-icon-concept-d-academic-orbit.svg`
  More editorial and academic. Circular mark with orbit and knowledge motif.

These are vector concept files so one direction can be refined into the final app icon set later.
